## Overview

Moonscraper is the leading chart editor for Clone Hero, Phase Shift, and Guitar Hero custom songs, supporting .chart and .mid formats with a MIDI piano-roll interface and built-in playback.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Moonscraper Chart Editor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Piano Roll View** | MIDI-style note editor with velocity, sustain, and forced-note controls |
| **Multi-Track Edit** | Edit guitar, bass, drums, and vocals in a single tabbed workspace |
| **Playback Engine** | In-editor song preview synchronized to the chart for instant feedback |
| **Export Formats** | Save as .chart or .mid compatible with all major rhythm game engines |
